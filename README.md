# Financial Lab 4.0.2 — Recurring Bills Manager

Development release for the Financial Lab DEV preview.

## What changed
- Add, edit, and delete recurring bills inside Financial Profile.
- Save bill amount, next due date, frequency, priority, and autopay.
- Dexx automatically expands recurring bills into each payday window.
- Paid status is stored per bill occurrence, so next month's bill returns automatically.
- Payday Mode, reserves, Financial Timeline, and recommendations use the saved bill list.
- Existing browser data remains under `financial-lab-v3-data`.

Upload the files in this ZIP directly to the root of the DEV repository.
